# Shared foreground presentation

Implements the scope of [LAV-211's infra plan](https://github.com/lavasecurity/lavasec-infra/blob/main/plans/2026-10-06-shared-rn-foreground-and-guard-parity-plan.md). RN owns the foreground page compositions and measured Guard handoff. Swift owns service truth, authorization, persistence and confidential native memory. Android integration supplies platform adapters; this change does not deliver an Android application or qualify its VPN service.

## Page ownership

| Surface | Shared RN composition | Native authority |
| --- | --- | --- |
| Custom DNS and blocklist source | `CustomEntryScreen`, shared fields/panel/action | Visit identity, entitlement, validation, rule budget; DNS stages its parent selection and blocklists stage the captured filter draft |
| Filter create/rename/library review | `ForegroundFlowScreen` | Captured library/filter visit, identity policy, current staged session equality and commit |
| Automation instructions | `HelpScreens`, shared setup sections | Opening Shortcuts or Settings on an explicit action |
| Full license reader | `LicenseReader` | Packaged, lockfile-derived notices |
| Feedback wizard, review, preview and receipt | `FeedbackFlow` | `FeedbackDraftSession`, diagnostics sampling, reviewed context, POST state, clipboard and haptic receipt |
| WireGuard configuration form | `VPNEditorFlow` | Parent VPN draft/revision, file picker, strict bounded UTF-8 read, configuration parsing and staging |
| Foreground Guardian | `GuardianDrawing`, shared paths/palettes/frame equations | Confirmed protection state, gesture recognition and haptic semantics |
| Onboarding stages and Guard transition | `OnboardingSurface`, `OnboardingFlow`, shared wave/travel equations | `OnboardingVisitState`, permissions, saved choices/defaults and completion marker |

The normal foreground flow mounts an independent command store in the existing UIKit modal owner. Its child can finish a parent command awaiting dismissal. Neither owner presents a second sheet. A native closing identity retains only an already-delivered outgoing frame while UIKit dismisses it; it cannot authorize further input. Security covers remain above the presentation and revoke its actions before stale asynchronous results can be delivered.

## Visits and privacy

Every mutation carries the native visit ID. Filter operations also bind the captured filter visit or reviewed library session. WireGuard staging binds the parent draft ID and revision. Authorization is checked again after suspension; changed visits, read grants and entitlements cannot write into a replacement page.

Custom source fields disappear behind the privacy cover when their native projection is revoked. Reentry waits for the current active native snapshot and authorizes the same retained visit beneath the resume cover. The visit-bound `customEntry.enter`, `vpnEditor.enter` and `foreground.enter` commands, plus the page-admission command `vpn.enter`, may prepare their presentations before hydration completes, alongside existing permitted query and presentation work. Saves, submissions and ordinary actions remain blocked. Waiting for hydrated fields before authorizing those fields would deadlock the retained form. The WireGuard form retains its original native input owner through concealment and reauthorizes that owner without redirecting to another flow or losing its unsaved native buffer.

The filter detail's native visit belongs to its retained navigation route. Revocation removes its private body and accessibility values without invoking `filter.close`; only removal of that route ends viewing. This keeps an authorized custom blocklist form bound to the same parent epoch and draft after authentication, while ordinary real-pop cleanup and read-only/filter identity checks remain in force.

The DNS page, DNS picker, VPN chaining parent and Explore page retain their transient bodies beneath an opaque, noninteractive, inaccessible cover. Removing the VPN body would run `vpn.cancel` and close its retained WireGuard child. Removing the DNS bodies would lose the original parent selection context and picker token before custom entry can stage its result. Explore retains its selected inspection and scroll context; lifecycle changes still pause or stop its demo, and fresh native fields gate every settings destination. The DNS provider exposes an empty draft while authority is revoked, retires callbacks from every authorization turn, and restores the same dormant draft only for the unchanged owner and policy. Actual route removal or native owner/policy replacement retires the retained state. Other private route bodies retain the existing discard-on-revocation policy.

VPN chaining admission requires the current native Settings grant before private row metadata or actions become available. `vpn.enter` authorizes presentation without beginning, committing or discarding a draft. A biometric inactive pause conceals the page while preserving its one pending request; backgrounding or route, owner or security-turn replacement retires that request. A completed promise alone cannot admit the page. Cancellation leaves only the exact focused route after foreground hydration settles. A separately presented native WireGuard child keeps the underlying RN page focused in its own navigator; its published public visit identity therefore suspends parent admission and input. The child alone requests resume authorization. Parent callbacks check current native child ownership before navigation or mutation, and child arrival/removal advances their request fence. Cancelling child authentication retains the same parent draft beneath its cover; only fresh native child removal can resume parent admission. Parent input ownership is separate from privacy concealment: a currently authorized parent keeps its existing paint below the native modal, and only an explicit native privacy opt-out permits its accepted paint during a read pause. Revoked protected or unknown authority remains concealed. Any parent cover is inaccessible while the child owns authorization; its toolbar callbacks still require current parent admission.

The custom-entry route retains its component through concealment; only actual route removal runs the native draft retirement callback. Covered library create, rename and delete flows also expose an explicit authorization retry. Cancelling a prompt cannot reveal fields, submit a draft or strand the user on an empty sheet when the read revision does not advance.

Ordinary form fields and in-sheet catalog search keep their native text buffer during uninterrupted typing. `BufferedInput` reuses the existing UIKit field leaf on iOS and an uncontrolled RN text input on Android. Labels, panels, search filtering, validation, and submission remain shared RN composition. React receives committed edits without echoing each value back into the editor. An explicit reset revision, such as one accompanying an imported configuration name, resets the buffer once; a delayed React acknowledgement cannot reset it. The WireGuard native adapter publishes `nameResetRevision` and advances it only when an import supplies a name. Its typing acknowledgements and privacy reentry leave that revision unchanged. Remounting an authorized custom form seeds the same retained local draft. Single-line inputs use the native system label color, green caret and Done action, with automatic spelling and smart insertion disabled. Feedback prose retains the native neutral caret, sentence capitalization, spelling, smart insertion and keyboard suggestions. Its paragraph metrics, text-container padding and placeholder alignment follow the native TextEditor captures. A dedicated simulator journey checks three uninterrupted URL edits, including repeated characters, before any security transition. Confidential WireGuard content remains outside the ordinary text-field contract.

Feedback progresses from editing to preparation, sending and receipt. The iOS field leaf bounds committed input by composed characters while preserving marked keyboard composition; native draft services independently enforce the same limits. Authoritative corrections use an explicit reset revision guarded by the latest edit epoch, including after reentry. Ordinary acknowledgements never overwrite later typing. The prose editor starts at the native 96-point minimum and reports its measured natural content height. The character counter uses native caption-two sizing, tabular digits, limit color and localized visible and accessible numbers. A visit-bound metadata-only dirty hint reaches UIKit immediately, ahead of queued diagnostics sampling, and keeps that editing visit guarded until dismissal or its sent receipt. The hint changes no report context or reviewed revision, grants no read authority, and cannot unlock preparation or sending. Submission consumes the exact reviewed revision, freezes its normalized context and refuses ordinary dismissal throughout preparation and POST. A forced retirement never retracts an accepted POST or makes a replacement visit eligible to replay it. Diagnostic previews are authorized ephemeral results and are cleared on inactivity, rather than entering the generic read cache.

Feedback keeps at most one native write in flight per field. Edits during that write replace its pending local value; the next write carries the latest edit, rather than a queue of stale snapshots. Review, step navigation and diagnostics preview disable editing, wait for the native final-text/blur acknowledgement to commit keyboard composition, and then drain every current field. Preview never removes a still-focused editor; returning from it preserves the draft and leaves Review usable. Repeated navigation is locked while waiting. Failed writes retain the local buffer for a subsequent authorized edit or reentry. Retirement releases any focus wait without advancing Review or requesting diagnostic examples; retired or concealed visits cannot replay their pending values.

Diagnostics preview retains the native information section, empty-summary explanation, lifecycle event examples and safe-data footer. Its label/value pairs measure their localized natural widths and stack together when they cannot fit. The shared form scaffold owns paragraph roles, the diagnostics headline, read-only review rows and dividers; page code only arranges them. RN owns divider placement and hairline dimensions. On iOS, a passive native leaf draws the actual SwiftUI `Divider()` in the selected appearance without input or accessibility ownership. Android uses the shared hairline view painted with `colors.separator`. Feedback's fixed footer uses the same primitive. Its native foreground host permits the scroll body to paint through the bottom container inset; the shared footer still owns safe-area padding. This is scoped to Feedback and does not change keyboard or authorization behavior. Preview Back reuses the retained draft, and the native text leaf reapplies paragraph attributes whenever its buffer is reseeded, including Fabric recycling.

WireGuard configuration text never appears in Fabric props, events, snapshots or RN state. The bounded native editor receives only an owner ID, placeholder and font size, and reports a boolean focus event for shared layout. Configuration remains in native memory; saved keys are never reloaded for display. Imports are security-scoped, capped at 64 KiB plus one detection byte and decoded strictly as UTF-8. Import completion checks the owner, parent revision and authorization revision. Retirement invalidates imports and clears the buffer.

A confirmed Security-off presentation may retain only the already painted, revealed configuration of the same current visit while foreground read authority is pending. The native interaction freeze preserves that display and does not resign its existing responder; hit-testing, mutation callbacks, native edit-menu actions and accessibility remain gated until current authority returns. This retention performs no configuration read or rehydration. Opted-in or unknown privacy policy conceals the configuration, clears the displayed text and resigns the responder. Actual owner replacement or window detachment does the same. A concealed configuration requires explicit Show configuration after authorization; authorization alone never reveals it.

During that display-only pause, the RN root uses `box-only` only when the current native privacy policy is explicitly off, the accepted foreground visit matches this modal's context, and its WireGuard editor projection is present and revealed. Fabric keeps this ancestor UIView enabled for UIKit responder continuity while its hit test consumes touches at the inert container without visiting children. The entire body remains inaccessible; native edit/menu/delegate gates and AppStore command epochs still deny actions without current authority. Other flow kinds, changed visits, missing or concealed editor projections, protected/unknown policy and ordinary hydration pauses keep the existing `none` fence. Fresh active authority restores the normal `auto` hit test. The same existing root keeps `collapsable={false}` throughout every phase: Fabric flattening must not detach a native editor when a privacy or hit-test prop changes. The lifecycle tests assert the same root and retained body across these phases; actual simulator captures qualify responder and geometry continuity.

The existing SwiftUI modal host owns iOS keyboard avoidance for the WireGuard form. Its shared `FlowSheet` keeps the same wrapper but opts out of RN padding avoidance on iOS, so simultaneous native and RN keyboard changes cannot briefly shrink the viewport twice and move the accepted editor. Other form sheets retain their existing avoidance, and Android retains its existing behavior. The configuration form measures its actual sheet scroll viewport and subtracts the current native header's measured inset. Focus or viewport changes shorten the existing fixed editor to fit between the translucent header and keyboard, then reveal its top anchor with the native breathing room; typing and manual scrolling do not trigger another reveal. The rotation journey checks both exposed geometry and screenshot OCR of newly typed text inside that editor, so an accessible buffer hidden beneath the header or keyboard cannot pass. Footer actions measure their localized headline labels and choose a complete horizontal or vertical group, matching the native `ViewThatFits` behavior at large text sizes. Nonempty drafts retain the native Save admission rule; strict configuration validation still runs only on an explicit Save action.

Real onboarding persists choices through the original app-services methods; QA onboarding remains transient. Navigation cannot jump to an unvisited step, bypass VPN installation or leave the final opening phase. Native permission outcomes determine completion. The final marker is written only after the native timed release gate and the final action.

## Motion and geometry

Foreground Guardian paths, palette stops and frame equations derive from the native renderer used by widgets. The Swift and Jest tests consume 434 shared samples across every state pair and blink boundary. These numerical tests supplement real render comparisons; they cannot qualify colors, strokes, compositing or timing on a device.

One RN tree measures the onboarding source and the actual Guard panel, mascot and action. No periodic geometry messages cross the native bridge. Zero, non-finite or out-of-panel measurements cannot complete arrival. Rotation retires old measurements; changed destinations retarget travel from the visible position and preserve its finish time. No guessed destination is substituted. An eight-second measurement failure offers retry.

An independent native stack presents setup over the retained main navigator. Its full-window modal owns touch delivery, safe areas and status-bar style. UIKit's bounded status-bar capture applies only to that setup modal. Closing a QA preview cannot replace the retained runtime's foreground factories. Measurement callbacks are bounded so a retired destination cannot starve the source or subsequent measurements. Phase acknowledgements reset on Back and retry, and late replies cannot settle a replacement arrival.

There is one persistent onboarding Guardian. The sequence retains the authored lava drain, facial reaction, travel, delayed panel reveal, Open Guard sleep and release timings. Timed drawing uses a monotonic clock; each owner cancels obsolete frames on replacement or inactivity. Reduce Motion changes page movement while retaining the native facial reactions and welcome waves. Protection material continues to follow confirmed native truth and its existing interruption policy.

The welcome floor and outgoing copy drain over the measured safe content height. The final page fades out its preceding content and footer while preserving the footer's measured layout; its controls leave the accessibility tree immediately. Back animates the Guardian to its source slot with the native 400 ms ease-in-out return.

## Android adapter contract

The shared iOS switch reserves UIKit's alignment rectangle and lets its native paint extend beyond that slot, matching SwiftUI layout without guessed control offsets.

The shared pages import platform-neutral semantic contracts. Metro selects iOS implementations today. Android must implement these bounded roles, rather than fork the pages:

| Adapter | Required behavior |
| --- | --- |
| Semantic colors and text metrics | Same token names, appearance override, native text scaling and naturally wrapped content |
| Navigation/sheet chrome | Native Back/Close/actions, gestures, safe areas, keyboard avoidance and dismissal attempts |
| Glyphs/material | Registered semantic symbols and the platform's bounded material implementation; no page body |
| Emoji field | One committed emoji grapheme, composition-safe input, selection/replacement and native emoji keyboard |
| Ordinary keyboard fields | Uninterrupted native edit buffer, explicit revision resets, composed-character limits, keyboard traits, semantic colors, text scaling and measured prose height |
| Confidential WireGuard field | Owner-ID-only contract; configuration remains in native memory; no saved-key rehydration; same-visit accepted display retention grants no reads or edits; opted-in/unknown concealment and owner/window retirement clear the display and resign input |
| File picker | Single selection, balanced document access, bounded strict UTF-8 read and stale-result rejection |
| Guardian contact | Same contact/start/end/tap/hold semantics, cancellation, ancestor-scroll conflict and haptic meanings |
| Privacy brand/locked glyph | Bounded decorative presentation without protected expression or stale content |
| Platform services | Permission/install truth, settings/Shortcuts equivalents, protected storage, clipboard and feedback transport |

The iOS root lifecycle/security owner, network extension, Keychain, widgets and system permission UI remain native. The fallback components entry point still fails for an unsupported platform. Providing the above mappings and Android service integration is a separate qualification task; an iOS build is not proof of Android support.

## Qualification and release

Run the full RN pipeline, package tests with warnings as errors, pinned generated graph/containment checks, native app and extension builds, and the plan's phone/tablet, appearance, text, input, navigation, motion and privacy matrix. Compare baseline and candidate screenshots plus intermediate recording frames at matched settings. Preserve source/bundle/lockfile hashes and actual results; neither source checks nor a broad pixel threshold replace visual review.

`build-full-app.sh --journeys` requires every ordinary simulator journey, with the minimum count enforced by `full-app-journey-lanes.json`, zero failures and zero skips. It then changes the private simulator's real Settings preferences and verifies UIKit before mandatory Reduce Motion and Cross-Fade passes. The same compiled app and test bundle run both iPad story/rotation cases. Each phase retains its own strict result summary, screenshots and recordings; a failed, skipped or missing phase cannot produce a passing receipt or review ZIP.

The isolated Debug simulator's store namespace is derived from Xcode's generated simulated signing entitlements. An initial signed build supplies that public prefix; a second build binds the existing Info setting to it. Before any journey executes, the fixture checks the app and tunnel's matching shared group and Widget/Intents exclusion. Missing, unqualified or mismatched metadata fails the lane. This requires no developer credentials and changes no production entitlement or Keychain policy. The receipt explicitly excludes device signing qualification; the later signed QA archive/export verifies the real distribution identities and entitlements.

The 15 existing installed-QA fixture cases retain their explicit opt-in and saved metadata requirements. `full-app-journey-lanes.json` records their separate qualification boundary; they are not scheduled on a fresh Debug simulator and are never reported as passing there. Cross-Fade is excluded from the ordinary-motion tour only because it executes in the separate mandatory, verified system-preference phase. A selector contract test ensures no ordinary journey falls outside the required minimum.

Merge only the qualifying implementation head with required checks and resolved reviews. Inspect a signed dry archive/export of the exact merged main SHA before creating an immutable ordinary RC tag. Verify both production internal TestFlight and QA dispatcher receipts. Record hardware-only VPN, biometric, permission and haptic checks explicitly when they cannot be performed; signed archives and simulator evidence do not establish those results.
